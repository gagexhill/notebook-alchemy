Notebook Alchemy · brand exploration, round four

NotebookLM's arches, with an alchemy bottle

The arches nest the same way as the NotebookLM mark, anchored on the left, and a small gold bottle stands in the space under the innermost arch. The first one is the version the icon package is built from; the two variants show the same idea with the decomposition drawn more explicitly. Every specimen is one SVG file on a 192-unit grid, drawn from scratch rather than traced.
